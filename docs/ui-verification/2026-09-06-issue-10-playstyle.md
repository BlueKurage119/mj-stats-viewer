# UI検証依頼: Issue #10 サマリー・カード3「打ち筋」（レーダー＋傾向2軸）

- **依頼日**: 2026-09-06
- **対象ブランチ / コミット**: `feat/issue-10-playstyle` / `3e46157`
- **所要時間の目安**: 約 25 分
- **なぜ逆発注するか**: 本カードは「バンドの呼称・タイプ名を出さない」というオーナー確定の下で、**2本のゲージだけで打ち筋を伝える**設計になっている。その伝わり方の当否は主観判断でしか測れない。加えて、傾向2軸の帯の校正（`Σ/k` → `Σ/√k`）が実データの母集団で妥当かは**複数の実プレイヤーの帯位置を見ないと分からず**、エージェントには母集団が無い。三麻（pl3）の母集団分布は API 方針上エージェントが一度も取得できておらず、**必要な metric が揃っているかが実データでしか分からない**。

## 準備

```bash
git switch feat/issue-10-playstyle
npm install   # 依存に変更はないので通常は不要
npm run dev
```

ブラウザで `http://localhost:5173/#/4/player/<ご自身の雀魂ID>/summary` を開き、サマリータブの3枚目「打ち筋」カードまでスクロールする。

カードは上から順に

- レーダー（5角形。軸は 攻・守・速・制・運。各頂点に数値）
- 傾向バー2本（1本目は左端が「守」右端が「攻」、2本目は左端が「門前」右端が「速度」。5マスのうち1マスだけ色が付き、その中に小さな三角マーカーがある）
- 脚注（「◯◯の間・半荘の全体分布との比較」）

> 終わったら dev サーバーは Ctrl+C で停止してください。

### V4. 帯の校正が実データで妥当か（**本依頼で最重要**）

> **背景**: 傾向2軸は「5マスのうちどこにいるか」で打ち筋を表します。設計上の想定は、母集団全体で **左から 7% / 24% / 38% / 24% / 7%** の人がそれぞれのマスに乗る、というものです。これが実データで極端にズレていないかを見ます。
