# UI検証依頼: Issue #12 サマリー・カード5「和銃分布」（ドーナツ3枚）

- **依頼日**: 2026-09-06
- **対象ブランチ / コミット**: `feat/issue-12-win-lose-donuts`
- **所要時間の目安**: 約 15 分
- **なぜ逆発注するか**: 本カードでは MD3 システムロール色（立直: `primary` / 副露: `tertiary` / 闇聴・門前: `secondary`）を採用した。段位シード5種および light / dark で配色が追従するため、**「見分けられるか」「各段位シードで喧嘩しないか」「3枚を通して同じ色が同じ意味に読めるか」は主観判断でしか測れない**。特に赤系の雀聖シードにおける視認性や、各シードでの3区分の区別は人間の目で判定する必要がある。

## 準備

```bash
git switch feat/issue-12-win-lose-donuts
npm run dev
```

ブラウザで `http://localhost:5173/#/__winlose` を開く（dev 専用の確認ページ。APIは叩かない）。

ページ上部に「カラーモード」（light / dark / system）と「段位シード」（既定/雀傑/雀豪/雀聖/魂天）のラジオがある。以降の手順ではこれを切り替える。

カード「和銃分布」はドーナツ3枚（左から `和了時の状態` / `放銃時の状態` / `放銃相手の状態`）で、各ドーナツの下に3行の凡例（立直 / 副露 / 闇聴 または 門前）が付く。

V4 だけは `#/__rank`（カード2）と並べて見る必要がある。

> 終わったら dev サーバーは Ctrl+C で停止してください（オーナーが別途起動している場合はそのままで構いません）。
