- **なぜ逆発注するか**: 本カードで初めて **段位シードから独立した3区分色**（紫・ティール・スレート）を導入した。コントラスト比は検収で機械計測済み（全3色・light/dark とも背景比 3:1 以上、相互比 最小 1.27）だが、**「見分けられるか」「同じ画面の他の色と喧嘩しないか」「3枚を通して同じ色が同じ意味に読めるか」は主観判断でしか測れない**。特に light のスレート `#728a96` はカード2の2位色（銀 `#50585f`）と同系であり、混同の有無は人間の目でしか判定できない。
