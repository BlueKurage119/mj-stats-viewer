# UI検証依頼: Issue #9 サマリー・カード2「成績」（順位分布ドーナツ）

- **依頼日**: 2026-09-06
- **対象ブランチ / コミット**: `feat/issue-9-rank-donut` / `8fd6611`
- **所要時間の目安**: 約 15 分
- **なぜ逆発注するか**: レイアウト（縦積み / 3カラム）の切り替わりと、凡例の新しい表記「1位 11回 (20.4%)」の読みやすさは、寸法が正しいことを機械で測れても「窮屈か」「情報が多すぎないか」は判定できない。実機スマホでの表示と、OS のダークモードを実際に切り替えたときのドーナツ4色の識別しやすさも、エージェントの環境では再現できない（ブラウザペインは `prefers-color-scheme` のエミュレーションで `matchMedia` の `change` を発火しない）。
