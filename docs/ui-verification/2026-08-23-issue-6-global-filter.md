# UI検証依頼: Issue #6 グローバルフィルタ（モード複数選択・期間プリセット）

- **依頼日**: 2026-08-23
- **対象ブランチ / コミット**: `feat/issue-6-global-filter` / `c07723f`
- **所要時間の目安**: 約 15 分
- **なぜ逆発注するか**: 実機（スマホ）でのタッチ操作の感触、sticky 表示の見え方、ライト/ダークの実切替による配色の印象は、いずれもエージェントのブラウザペインでは再現できない（`document.visibilityState === "hidden"` のため `prefers-color-scheme` の `change` が発火せず、実タッチも送れない）。またチップ列の折り返し方と「全モードを選ぶのに6タップ」の許容可否はオーナーの設計判断そのもの。
