# UI検証依頼: Issue #5 アプリシェル（ルーティング・タブナビ・レイアウト骨格）

- **依頼日**: 2026-08-23
- **対象ブランチ / コミット**: `feat/issue-5-app-shell` / `c489a30`
- **所要時間の目安**: 約 15 分（うち実機スマホ確認 5 分）
- **なぜ逆発注するか**: Claude Code のブラウザペインは `document.visibilityState === "hidden"` のため Web Animations が進行せず、タブ切替モーションと層状シートのスクロール体感を**再生された状態で見ることが原理的にできない**。`prefers-reduced-motion` の切替も OS 設定依存で、実機（スマホ）の表示・タップ感も同様。DOM の値・CSS 変数・要素サイズ・ルーティング挙動は検収担当が機械測定済みで、本書には含めていない。

## 準備

```bash
git switch feat/issue-5-app-shell
npm install   # 依存の追加はありません。念のため
npm run dev
```

ブラウザで `http://localhost:5173/#/4/player/123456/summary` を開く。

画面には次が出ます（中身は後続 Issue のためプレースホルダです）。

- 上部にヘッダー（左「mj-stats-viewer」、右「四人打ち / 三人打ち」トグル）
- その下にグレーの帯（ヒーロー領域。「プレイヤー: 123456」）
- さらに下に角丸で立ち上がる白い面（カード層。「タブ: summary」）
- ウィンドウ幅が狭いと画面下部にボトムナビ、広いと画面左端に縦のレール

### V2. `prefers-reduced-motion` 有効時にタブ切替のモーションが止まるか

**操作**

1. macOS: システム設定 →「アクセシビリティ」→「ディスプレイ」→「視差効果を減らす」を**オン**にする。
   （Windows: 設定 →「アクセシビリティ」→「視覚効果」→「アニメーション効果」を**オフ**）
2. ブラウザのページをリロードする。
3. ボトムナビで「サマリー」→「スタッツ」と切り替える。

**期待結果**

カード層の中身が**滑り込まず、フェードもせず、瞬時に入れ替わる**。中身自体は正しく「タブ: stats」に変わる。
