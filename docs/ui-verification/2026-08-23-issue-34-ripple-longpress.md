# UI検証依頼: Issue #34「md-ripple 長押し後のpressed残留」

- **依頼日**: 2026-08-23
- **対象ブランチ / コミット**: `claude/brave-maxwell-dd1b7e` / (このドキュメントと同じコミット)
- **所要時間の目安**: 約 5 分
- **なぜ逆発注するか**: 現象は実機のタッチ操作をOS/ブラウザが「タップ」ではなく「テキスト選択」や「コンテキストメニュー」と解釈したときにだけ再現する。これは実機のタッチイベント発火順序に依存しており、Claude Codeのブラウザペインは疑似的なポインタイベントしか送出できず、実機の長押し判定そのものを再現できない。

## 準備

```bash
git switch claude/brave-maxwell-dd1b7e
npm install   # 依存に変更がある場合のみ
npm run dev -- --host
```

ターミナルに出る `Network: http://192.168.x.x:5173/` のURLをスマートフォンのブラウザで開く。

> 終わったら dev サーバーは Ctrl+C で停止してください。

**この画面の仕様（前提知識）**
- 下部（または左側）のナビゲーションのタブ項目をタップすると、波紋（リップル）が広がって消える
- 今回の修正: タップ後に波紋が広がったまま消えなくなる不具合を、pointerup 後 500ms 経っても解決イベントが来なければ強制的に後始末する、という形で緩和した
